# SKKJ Autopart Website Upload

Upload these files to GitHub:

- `index.html`
- `skkj-version-2.html`
- `skkj-version-2-phone-preview.html`
- `assets/`

For GitHub Pages, `index.html` is the main website page.

Important:
- Keep the `assets` folder next to `index.html`.
- Do not rename the `assets` folder.
- This is a static test version. Orders and admin changes still save inside the browser, not a real cloud database yet.
